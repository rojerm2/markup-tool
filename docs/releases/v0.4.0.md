# PDF Markup 0.4.0

This release adds tools for working with large drawings and keeping editable
work safe, while retaining portable projects and local document processing.

- Recover unsaved work after a crash using bounded local checkpoints.
- Navigate with page thumbnails, PDF bookmarks, remembered views, and a searchable markup list.
- Select, move, copy, and edit multiple markups; hide or lock categories.
- Calibrate individual pages and measure lengths, areas, and perimeters.
- Reuse drawing defaults, category sets, and original symbol groups with portable presets.
- Export or print selected pages/categories, cancel processing, and see operation progress.
- Generate formula-safe CSV and paginated PDF reports with page mappings and measurement totals.
- Compare original drawing revisions with synchronized views, color overlays, and manual alignment.
- Retain font licensing notices and corresponding source in distributions; verify dependency advisories in CI.

## Install and compatibility

Download `pdf-markup-tool_0.4.0_x64-setup.exe` and `SHA256SUMS.txt` from this
release. Windows 11 x64 is the locally tested platform. Node.js and Rust are
not required; WebView2 is downloaded if missing. Normal editing works offline.
The installer retains the existing app identifier and current-user installation.
Back up projects before upgrading. Existing portable projects remain readable.
Saves use schema 2, 3, or 4 according to the included features; measurements,
calibration, and reusable drawing defaults require schema 4. Older releases
reject unsupported schemas instead of silently losing newer features.

Save `.pmarkup` for editable work; it includes the source PDF. Export produces
a shareable PDF. Printing uses an annotated preview and Windows print settings.
See the [user guide](https://github.com/rojerm2/markup-tool/blob/v0.4.0/docs/USER_GUIDE.md).

## Verification and limits

Frontend regressions, Rust persistence tests, formatting, lint, type checks,
license provenance, release metadata, dependency audits, and installer packaging
are required release checks. Desktop testing covers recovery, navigation, bulk
editing, measurements, presets, selective export/printing/reports, and comparison.
Large-PDF benchmarks confirm selected-page output preserves the retained
source streams. Timings depend on the document and computer.

- PDF input/export is capped at 256 MiB; annotation metadata at 16 MiB.
- Export parses the source document; complex CAD PDFs can consume substantial memory.
- Recovery files and portable projects are not encrypted. Markup is not secure redaction.
- Presets may contain annotation text. Measurements require accurate calibration;
  comparison is a visual aid and does not certify a drawing.
- RustSec reports unmaintained Unicode crates in Tauri's Windows dependency chain.
  No known vulnerability was reported in the release review; see the
  [security policy](https://github.com/rojerm2/markup-tool/blob/v0.4.0/SECURITY.md).
- Signature status is recorded below by the release workflow. Unsigned builds
  may show Windows publisher warnings. Installation on another computer remains
  dependent on that computer's Windows, WebView2, and organizational policies.
