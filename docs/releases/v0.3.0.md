# PDF Markup 0.3.0

Windows x64 release with portable PDF projects, vector markup/export, resizable
legend and text boxes, custom app menus, printing, dark mode, recent files,
and live highlight thickness/color previews.

This release adds:

- Consistent formatting, linting, pinned development toolchains, and release-version checks.
- Windows CI, tagged release builds, installer artifacts, and SHA-256 checksums.
- A content security policy excluding dynamic JavaScript evaluation, and removal of unused starter commands/permissions.
- MIT licensing, bundled third-party notices, user/contributor/security guides, and release procedures.
- Product/publisher metadata and a current-user installer that retains the existing app identifier.

## Install

Download the x64 setup executable and `SHA256SUMS.txt` from this release.
Run the installer and launch **PDF Markup**. Node.js and Rust are not needed.
WebView2 is downloaded if missing. Windows 11 x64 is the locally tested platform.

Save editable work as `.pmarkup`; it includes the original PDF.
Use Export Annotated PDF for sharing. Print opens an annotated preview;
use its printer icon and **Print using system dialog** for Windows print settings.

## Known limits

- PDF input and export are capped at 256 MiB; annotation metadata at 16 MiB.
- Export rewrites the entire PDF; complex CAD files can require substantial memory.
- Unapplied text/property drafts are excluded from save, export, and print.
- Projects are not encrypted; markup is not secure redaction.
- Signature status is recorded below by the release workflow. Unsigned builds
  may show Windows publisher warnings.
